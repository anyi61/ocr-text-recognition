# OCR文字识别助手（浏览器插件）

## 用途
这个插件用于在网页中快速框选截图并识别文字（OCR），适合：

1. 需要从禁止复制或不易复制的页面提取文字。
2. 需要将截图中的文字快速转为可编辑文本。
3. 在不同 OCR/多模态服务间切换使用（如 Claude、OpenAI、智谱、百度、阿里云、兼容接口等）。

## 如何使用

### 1. 安装插件（开发者模式）
1. 打开浏览器扩展页面：`chrome://extensions/`（或 `edge://extensions/`）。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目目录。

### 2. 首次配置
1. 点击浏览器工具栏中的插件图标。
2. 点击右上角设置按钮进入配置页。
3. 选择一个 API 提供商并填写对应密钥/参数。
4. 返回弹窗页面，确认可开始识别。

### 3. 开始识别
1. 在目标网页打开插件弹窗。
2. 点击“开始截图识别”。
3. 在页面上拖拽框选文字区域。
4. 调整选区后确认识别。
5. 在结果弹窗中复制文本，或在历史记录中再次查看/复制。

### 4. 快捷键
- `Ctrl + Shift + S`（macOS 为 `Cmd + Shift + S`）：快速开始截图识别
- `Esc`：取消当前截图流程
