使用说明

  1. 配置您选择的API提供商的密钥
  2. 点击插件图标打开弹出窗口
  3. 点击「开始截图识别」按钮
  4. 在页面上框选需要识别的文字区域
  5. 等待识别完成，复制结果即可

快捷键

  • Ctrl+Shift+S / Cmd+Shift+S - 开始截图识别
  • ESC - 取消截图
  • 鼠标拖拽 - 框选区域

提示：可以在 chrome://extensions/shortcuts 中自定义快捷键

推荐API

  • Claude 3 Opus - 识别准确率最高
  • GPT-4o - 速度快，准确率高
  • GLM-4V - 国产大模型，中文效果好
  • 百度OCR - 中文识别效果好，性价比高
  • 阿里云OCR - 企业级服务，稳定可靠
  • 通用OpenAI接口 - 灵活支持多种服务商
