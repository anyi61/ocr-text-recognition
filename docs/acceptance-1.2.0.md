## 本轮功能

| 功能 | 行为 |
| --- | --- |
| 失败恢复 | 保留会话内原图预览；重试直接提交同一图像和新请求 ID，并读取当前供应商设置。打开设置不会清除原图；重新框选会重新截图。没有获得截图时禁用重试。图片导入页支持重试原图和重新选图。 |
| 重要历史 | 收藏、命名、名称搜索、导出。保留最新 50 条普通记录；收藏和未完成草稿（包括空内容草稿）不计入上限。仅命名不自动保护。解除收藏或完成草稿后，下次新增时重新按时间参与淘汰。 |
| 自动复制 | 默认关闭，可在设置独立开关。仅新 OCR 成功且该次请求启用时复制；翻译、历史恢复和编辑不触发。复制失败保留结果及手动复制。 |
| 翻译偏好 | 独立存储 `translationProvider`、`translationTargetLanguage`；固定初始默认 Claude／简体中文。只保存明确更改，恢复历史译文不写全局，能力刷新不覆盖用户选择。 |

旧功能继续保留：多服务商 OCR/翻译、译文快照及复用、编辑草稿、同区域再次识别、粘贴／拖拽／上传、文本整理、搜索／修订／导出历史、中英文及主题。

## 验收范围

| 场景 | 主要证据 |
| --- | --- |
| 正常流程 | 截图裁剪、PNG/JPEG/WebP 导入、真实 clipboard 读写、多服务商文本契约、翻译和历史复用 |
| 失败恢复 | API 拒绝/空结果/瞬态重试、原图字节一致、改设置重试、重新框选新像素、存储失败、剪贴板拒绝及手动恢复 |
| 取消 | 选区取消、请求中取消、重试取消、页面关闭、翻译取消、换图中止；后台真实请求中断，不写取消结果 |
| 并发 | 迟到请求/复制/偏好读取隔离，草稿版本冲突，保存等待期间继续编辑，收藏与命名串行合并、同字段旧回执不覆盖更新状态 |
| 持久化 | 浏览器重启保留收藏、名称、自动复制及翻译偏好；空草稿和收藏超 50 条保留；旧配置导入不覆盖缺省偏好 |
| 安装包 | 从实际 ZIP 解压启动 Chromium，验证失败重试、翻译、受保护历史及复用；检查封闭 Shadow DOM、生产资源和权限 |

单元／契约测试通过 VM 或纯模块调用验证状态、请求、取消和存储；浏览器测试验证实际 UI、后台消息和端口。除一项原生剪贴板成功测试外，剪贴板拒绝／延迟由临时测试副本注入。端到端临时副本仅为浏览器驱动开放 Shadow DOM，并授权本地 Mock 域名；生产包不包含这些测试注入。

安装包冒烟测试使用原始生产源码，不开放 Shadow DOM、不注入剪贴板或存储行为，仅在解压后的测试副本授权本地 Mock 域名。

## 限制与安装

所有 API 验收均使用本地 Mock，不代表真实供应商的可用性、准确率、翻译质量或计费行为已验证。失败原图只保留在当前会话，不跨页面重载恢复，也不写入历史。收藏和草稿免于条数淘汰，但仍受浏览器本地存储容量限制。

安装 ZIP 解压后，在 Chrome／Edge 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。该文件不是已签名的 CRX，也未发布至商店。本轮没有添加批量、表格、离线功能。
