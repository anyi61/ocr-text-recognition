## 结构调整

- 设置页以供应商字段映射生成保存补丁，删掉重复收集分支和无调用的旧分步导入函数。
- 翻译偏好模块只维护默认值与规范化，删除另一套写入队列；所有设置写入统一交给后台设置存储模块。
- 草稿的“本地内容尚未保存”判断、图片结果复制状态清理各自集中处理，避免多个事件分支采用不同规则。
- 保留截图交互现有边界和键鼠步长，没有为了缩短文件而整块重写选区逻辑。`content.js` 仍较大；本轮未将大文件本身列为功能故障。
