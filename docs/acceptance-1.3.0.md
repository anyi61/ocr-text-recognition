# 1.3.0 功能与验收记录

日期：2026-10-04。基线为已推送的 `66903d8`；完整继承 1.2.2 实现，不覆盖或重置原有工作。本轮完成 CI、历史备份恢复、编辑冲突处理和历史管理。真实供应商及桌面浏览器人工验收不在本轮范围，批量、表格和离线功能仍暂缓。

## 最终行为

| 功能 | 用户可见行为与数据保护 |
| --- | --- |
| CI 与构包 | 推送、PR、手动触发或 `v*` 标签后运行 lint、单元／契约及 Chromium E2E；成功后上传安装 ZIP、源码、提交状态元数据和校验清单。标签必须匹配版本。测试日志与报告始终上传，共享 fixture 提供失败截图及 trace。 |
| 历史备份恢复 | 接受版本 1、2、3 的历史 JSON，最大 20 MiB、10000 条。先展示新增、重复、容量跳过及受保护数量，确认后合并。重复 ID 保留本机记录，普通历史只补足剩余的 50 条空位，不挤掉当前记录；收藏及未完成草稿继续豁免。 |
| 冲突就地处理 | 截图结果、图片工作区和历史详情均可比较最新已保存正文。保留当前编辑继续修改，不立即写入；正式保存仍检查正文是否再次变化。也可另存新记录，即使原记录已被删除。 |
| 历史筛选与清理 | 收藏、未完成草稿筛选可结合搜索，搜索覆盖草稿正文，其他窗口的变化实时反映。普通历史清理预览明确覆盖全部历史，与筛选无关；收藏及未完成草稿保留，包括编辑为空文本的草稿。原有“清空全部”仍需明确确认。 |

恢复及清理预览绑定发起文档，有效期 5 分钟、单次使用。确认时再次验证历史修订及内容，其他窗口或外部存储变更会使预览失效；用户刷新后重新确认。取消迟到预览会释放令牌，失败保留备份选择。后台拒绝非 Popup 发起的管理操作。

导入仅保留历史白名单字段，移除草稿会话锁、未知数据，并将来源 URL 归一为站点 origin。恢复不导入凭据或改变全局翻译偏好。非法结构、超限、非法日期和持久化失败均不会先删除现有历史。

另存新记录保留原记录，包括原记录位于普通历史淘汰边界时；新记录使用独立 ID，并重新绑定草稿及翻译会话。另存期间正文暂时只读、旧草稿暂停写入，截图结果的合并换行／撤销同步禁用；响应成功后继续编辑新记录，失败后解锁原编辑器。关闭视图后迟到回执不会重新打开面板。另存和历史恢复不会触发 OCR 自动复制。

## 独立复查

实现按存储、历史 UI、冲突 UI 和 CI 并行分工，另有独立只读代理复查。复查发现并修复了两项可复现问题：

1. 超出 JavaScript Date 范围的备份时间戳能通过校验，随后导致日期渲染报错。现按可表示日期范围验证，并添加回归。
2. 另存等待期间允许继续输入，但旧草稿已暂停保存，直接关页会丢失新输入。三个编辑器现统一锁定正文及相关改文按钮，保存完成后恢复编辑，并覆盖等待期间关页及迟到回执。

独立代理另行执行 37 项定向单元／契约测试，全部通过；复查白名单、注入顺序、预览权限、空草稿保护和 Actions 只读权限，未发现遗留阻塞问题。

## 验收覆盖

新增端到端场景涵盖：实际导出的文件恢复、空历史恢复、重复及容量预览、取消、超限与损坏备份、并发变更失效、写入失败重试、筛选与草稿搜索、跨窗口更新、重启持久化；以及三种编辑器的比较、重复正文冲突、原记录删除后另存、读写失败、关闭比较、迟到回执、原记录保留、新 ID 后续编辑和草稿恢复。

安装 ZIP 解压后的冒烟测试使用实际生产文件，验证 OCR 失败后原图重试、翻译和历史收藏，并继续验证冲突另存、备份恢复、筛选和普通历史清理。测试副本只增加本地 Mock origin 权限，生产包不包含测试注入。

CI 构包和失败证据收集均已在本地验证；曾在临时失败用例中确认截图及 trace 产出，随后删除该临时用例。本地验收完成时尚未运行远端 GitHub Actions，远端结果以提交对应的 Actions 记录为准。个别旧用例自行创建浏览器，失败证据以报告、日志及其显式截图为准。

## 最终验证与交付

冻结实现后执行 `npm run check`：ESLint 通过，**281 项单元／契约测试、141 项 Chromium E2E 全部通过**（浏览器回归 3.8 分钟），无失败或跳过。相比 1.2.2 新增 31 项单元／契约及 22 项 E2E，并扩展了安装 ZIP 的冒烟流程。

`npm run release:artifacts` 生成以下产物：

- `dist/release-1.3.0/ocr-text-recognition-extension-1.3.0.zip`：开发者模式安装包。
- `dist/release-1.3.0/ocr-text-recognition-source-1.3.0.tar.gz`：实现、测试、文档及 CI 工作流快照。
- `dist/release-1.3.0/SHA256SUMS`：安装包、源码及元数据的 SHA-256 校验清单。
- `dist/release-1.3.0/release-metadata.json`：版本、构包时间、Git 提交与工作区状态。
- `dist/acceptance-1.3.0/`：全量及定向日志、安装后截图和产物核验结果。

以上本地产物记录开发验收时的提交前快照，元数据保留实际基线提交并标记 `dirty: true`。后续仓库状态以 Git 提交为准，CI 产物记录其对应提交；此前提交及旧版本归档继续保留，构包不会自动创建远端 Release。

所有服务调用验收使用本地 Mock；未验证真实供应商识别／翻译质量，也未执行真实桌面 Chrome／Edge 人工验收。安装 ZIP 用于开发者模式加载，不是签名 CRX，未发布至商店。
